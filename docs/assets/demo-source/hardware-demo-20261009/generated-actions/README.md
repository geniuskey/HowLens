# 매뉴얼 참조 기반 AI 작업 장면

원문 이미지를 직접 imagegen에 참조로 제공해 작업 동작이 달라지는 카드형 이미지를 생성한다. 원문 그림의 반복 사용만으로 만든 기존 스토리보드는 `../manual-storyboards/`에 보존한다.

진행 순서: MagnaTran → LOGOSOL → STM32.

- MagnaTran: Figure 9-4·9-5 및 Table 9-4를 참조. 밴드 두께 측정, 힘 게이지 접촉, 시계/반시계 조정, 재측정.
- LOGOSOL: Figure 3-4의 실제 octa-box 내부 사진을 참조. 동일 배선·센서·조정기 위치에서 도구 접촉 및 A/B 조건을 설명. 생성 LED 상태는 실제 측정 기록이 아니다.
- STM32: Figure 7 MB1136 보드 도면을 참조. 동일 CN2 두 핀 쌍에 두 점퍼를 장착하는 중간 장면을 설명.

생성 결과는 실제 장비 사진이 아닌 데모 설명 이미지다. 원문에 없는 손과 도구 동작은 설명을 위해 추가하며 장비의 형상·배선·장착 위치를 변경하지 않는 것이 검토 기준이다. 실제 작업/안전/정상 동작 검증은 수행하지 않는다.

제품 구현·API 통합·Git 변경은 진행하지 않는다. 후속 구현은 orchestrator가 담당한다.

원문 이미지와의 픽셀 일치 자료가 아니라 원문을 참조한 생성 설명 이미지입니다. references/에 원문 비교 자료와 단계별 출처를 포함했습니다. LOGOSOL A/B의 LED 상태는 절차 설명을 위해 합성했습니다. 기존 원문 반복본과 구분해서 사용하세요.

## 검토 상태

세 예제 모두 원문 이미지 참조 생성 후 한 차례씩 국소 수정했습니다. 생성 결과가 원문과 기계적으로 완전히 일치한다고 보증하지 않습니다. 특히 MagnaTran의 도구 접촉면과 STM32의 CN2 핀·접점 세부 묘사는 실물 대조가 필요합니다. 검토 항목은 review.json에 기록했습니다. 데모 설명용 시안이며 실제 작업 지시나 성공 증거로 사용하지 않습니다.
