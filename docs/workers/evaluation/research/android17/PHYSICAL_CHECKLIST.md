# 두 탭 실기기 UX 인계표 — 모두 미실행

App/Coordinator가 단말 slot을 확보한 뒤 수행한다. 모델 SM_S948N/OS 표시 Android17은 전달받은 값이며 실제 SDK_INT는 담당자가 기록한다. APK SHA·모드·날짜·각 케이스의 PASS/FAIL/BLOCKED/미실행을 적고, 개인 사진/장비 시리얼/계정/알림이 없는 합성 카드(큰 글자 A/B, 색상 블록)만 사용한다. 실물 설비 조작·paid API 호출 없이 mock 경로로 시험한다.

시작 전: `사진 분석` / `카메라` 두 탭이 있는 대상 APK인지 확인. 테스트용 설치의 권한 초기 상태를 기록한다. first-grant/deny를 재현하려면 소유자가 앱별 카메라 권한 상태를 설정에서 준비한다. 데이터 초기화나 공유 기기 전체 설정 reset은 하지 않는다. 한 번 거부/영구 거부/한 번만 허용 UI는 OS/상태에 따라 다르므로 실제 보인 문구와 분기를 적는다.

| 순서 / 상태 준비 | 동작 | 기대 결과 / 기록 |
|---|---|---|
| 1 사진 탭·미선택 | 앱 열기, 사진 선택으로 합성 A 선택 | 카메라 권한을 먼저 요구하지 않음; A 전체 구도·회전 확인; 질문 editable; 승인 전 자동 전송 없음 |
| 2 카메라 권한 미결정 | 카메라 탭→허용→합성 B 촬영 | 로컬 preview; 의도적 촬영 후 B 고정; 질문 입력→확인으로 단일 사진 처리. preview 중 cloud 분석/임의 guide 없음 |
| 3 권한 미허용 | 카메라 탭→거부 | 검은 preview 무한 대기/크래시 없음; 짧은 오류와 사진 탭 fallback; 사진 선택 가능 |
| 4 재요청 불가 상태 | 카메라 탭→설정 열기→앱 권한 허용→Back | 복귀 시 현재 permission 재확인, preview 정상 재개 또는 명시적 재시도; 이전 거부 상태가 영구 고정되지 않음 |
| 5 권한 철회 복귀 | preview 밖 설정에서 권한 철회→Back | 상태 재확인과 fallback. OS가 프로세스를 종료한 경우 그 사실을 구분; stale preview/보안 예외 없음 |
| 6 회전 | preview 세로→가로→세로; 촬영 B; review에서 다시 회전 | crop/회전/글자 방향 일치, preview 중복 binding 없음; review의 B/질문 보존; 다시 live 프레임으로 바뀌지 않음 |
| 7 background | preview→Home 10초→복귀; review에서도 반복 | background에서 카메라 사용 종료/복귀 재개; review는 고정 사진 그대로. 강제 process death/장기 보존은 별도 범위로 표시 |
| 8 탭 전환·사진 보존 | 사진 탭 A/질문 입력→카메라→촬영 취소→사진 탭 | A/질문 초안 보존. B를 명시적으로 채택하면 현재 분석 대상이 B임을 확인; 숨은 이전 사진 전송 없음 |
| 9 분석 취소·뒤로 | mock 분석 시작→취소 또는 Back→입력 수정 | 사진/질문 유지; 이전 늦은 결과가 새 입력을 덮지 않음; 자동 재요청 없음 |
| 10 IME | 한국어 긴 질문·조합 중 입력, 마지막 줄·CTA까지 스크롤, IME 닫기 | 필드/오류/CTA 가림 없음, 중복 inset 큰 공백 없음, 조합 글자 손실 없음; 공백/2,000자/초과 validation |
| 11 큰 글꼴 | 기존 기기 글꼴 설정 기록→1.3배 상당/최대 2배 상당→두 탭/결과/근거 확인 | 48dp 대상, 필수 경고 잘림 없음, 탭·CTA 줄바꿈/스크롤, 긴 URL 읽기 가능. 완료 후 원 설정 복원 |
| 12 접근성과 결과 | TalkBack으로 탭/카메라/공유/근거/닫기 이동 | selected 탭과 목적 label, 논리 순서, 상태 텍스트; non-guide 단계 없음; demo 분명; 복귀 시 초점 유지 |

기록 최소형: `APK SHA / OS release·SDK / initial permission / case / expected / actual / PASS|FAIL|BLOCKED / 재현횟수 1 / 담당자`. 각 불일치는 화면 1장과 민감 정보 없는 짧은 재현으로 충분하다. 프로세스 재생성에 따른 초안 보존 실패는 숨기지 않고 회전/단순 background 실패와 별도 표시한다. 동작 확인은 설비 안전·정상 동작·실제 AI 정확도 검증이 아니다.
