# 구현 인수 기준 — 실행 전 체크리스트

모든 APK 항목은 **미실행**이다. 완료 체크로 오인하지 않도록 체크박스를 비워 둔다. 문서/에셋 검증 결과는 REPORT.md에 별도로 기록한다.

## 가장 먼저 확인할 10개

- [ ] 앱 실행 후 설정/소개문을 읽지 않고 선택 탭의 `사진 선택` 또는 `촬영`을 찾을 수 있다. 사진 없는 화면에 자동 분석/실시간 전송 표시가 없다.
- [ ] 320/360/412dp 세로 화면에서 48dp 터치, 56dp 최소 CTA, body 16sp 이상. font_scale 1.0/1.3/2.0에서 주요 문장·버튼이 잘리지 않는다.
- [ ] keyboard/gesture nav/3-button nav/cutout을 각각 확인. 질문과 오류가 IME 뒤에 가려지지 않는다. landscape에서 버튼만 남고 내용이 사라지지 않는다.
- [ ] TalkBack 순서가 모델→사진→질문→주행동이며 설정/뒤로/닫기/패널/근거에 목적 중심 label이 있다. 색을 없애도 stop/needs-info/guide가 구별된다.
- [ ] 모드 `데모`는 모든 mock 상태에서 유지되고 mock 결과는 실제 작업 금지 표시. live를 안전 승인으로 해석할 표현이 없다.
- [ ] non-guide의 steps/visual/verification 진입이 없다. 필수 미충족 조건·중요 warnings는 접히거나 ellipsis되지 않는다.
- [ ] guide의 N단계와 9패널 수를 혼동하지 않는다. 각 panel은 실제 step_id와 연결; 이미지 실패에도 텍스트/근거를 읽을 수 있고 재생성은 최대 1회다.
- [ ] 취소/뒤로/설정 복귀/네트워크 실패 시 장비·사진·질문을 잃지 않는다. 늦은 이전 응답이 새 입력을 덮지 않는다.
- [ ] 출처에는 원문 quote·문서 판본·1-based PDF page·printed_page null 대응이 있다. 외부 문서 열기 실패가 조용히 무시되지 않는다.
- [ ] 공유 payload에 사진·시리얼·IP·분석 ID·원문 질문·토큰이 없다. mock/stop/한계가 유지되고 사용자가 실제 전송을 선택한다.

## 기능·오류 행렬

- [ ] 촬영 성공/취소/앱 없음, 갤러리 성공/취소/읽기 실패/413/415/20MP 초과.
- [ ] 질문 공백/1자/2,000자/초과와 한글 IME 조합. 분석 중 중복 요청 방지.
- [ ] needs-info: 사진 문제/모델 문제/근거 없음 각각 다음 행동 적절; 무조건 재촬영 아님.
- [ ] stop: 위험 설명을 숨기지 않고 guide 통과 버튼 없음.
- [ ] guide: 1단계/9단계, 긴 설명/긴 문서 URL, 미확인 조건, 사전 조건 전체 읽기.
- [ ] visual: queued/running/completed/failed, 이미지 decode 실패, 9패널 확대·큰 글꼴 단일열, 재시도 0/1회, mock API 차단.
- [ ] verification: before/after 회전·다른 각도·동일 사진·미입력·2,000자 확인 제한, 세 결과 enum 모두. observed_change를 완료로 부르지 않음.
- [ ] API: detail 배열/객체, retryable true/false, 404 재분석 수동 선택, 409, 422, 503, 504. 입력/텍스트 보존.
- [ ] light/dark에서 실제 렌더 색 대비, 햇빛/손떨림/실물 단말은 가능할 때 확인하고 미확보는 pending.

## 오늘 구현 우선순위

P0 45–75분 추정: theme 토큰 + 입력/결과 분리 + 설정 이동 + 짧은 copy + sticky CTA. P1 30–45분 추정: 단계/근거 sheet + 실패 복구/large font. 기존 visual/verification/shared 기능은 App 작업과 통합하되 새 백엔드 요구 없음. CameraX는 최신 사용자 확정 범위로 별도 prototype gate를 따르며, 폰트 다운로드/로고 정밀 제작은 막판 의존성으로 만들지 않는다. 16:00 이후 새 기능 대신 위 P0/계약 차단·복구 시험에 집중한다. 구현 속도는 App 준비도에 따라 달라지는 추정이며 검증된 일정이 아니다.

- [ ] 사진 분석/카메라 두 탭 selected semantics, 사진 초안 보존, 카메라 권한 거부/영구 거부/사용 불가의 사진 탭 fallback, 촬영→고정 검토→명시적 분석 순서, 탭 이탈 camera release. 영상 전송·자동 분석 없음.
