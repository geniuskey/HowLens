# Reference UI imagery

Visual composition follows the user-supplied `content.png` and `UI_REQUIREMENTS.md`, interpreted by `docs/orchestrator/REFERENCE_UI_BRIEF.md`. The board itself is not embedded as an interactive screen. Original user photos and reference files were not modified.

Both bundled photos are real hardware photographs without people, used as illustrative reference imagery rather than a diagnosis, model identification, SSD-specific photograph, or approved step illustration. CSS/Compose crop them only for home thumbnails; user capture/preview and guide imagery retain the complete frame.
