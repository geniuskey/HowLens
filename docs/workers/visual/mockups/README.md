# Visual mockups

For each visual work item, create a lightweight preview in this directory and
show it to the user. Use `YYYYMMDD_HHMM_mockup-content` as the filename/title
(local Korea time). Keep mockup effort small; use synthetic fixtures when useful
and label them explicitly. Mockups do not establish semantic image quality.

- `20261009_1112_storyboard_split_preview.png`: synthetic numbered color grid
  and its nine split panels, in row-major order; no real image generation.
