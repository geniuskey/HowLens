# Visual Worker — 이윤재

읽기: `docs/common/RULES.md` → `docs/workers/COMMON.md` → 이 파일 → `docs/common/CONTRACT.md` → `TASK.md`.
수정: `backend/visual/`, `docs/workers/visual/`. 현재 Task에서는 Android 경로를 수정하지 않는다.
역할: 승인 단계 기반 storyboard adapter, 패널 처리, 실패·시각 품질 평가.
실제 대상의 구조·위치 근거를 이미지에서 추정하지 않는다. 문구·번호·근거는 앱 텍스트로 표시한다.
9패널을 위해 없는 절차를 추가하지 않는다. 분할 성공과 패널 의미 검증은 별도다.
Windows 셸·경로를 사용하며 POSIX 명령을 그대로 실행하지 않는다.
