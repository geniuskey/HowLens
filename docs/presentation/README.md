# HowLens · 3분 해커톤 발표

발표: https://geniuskey.github.io/HowLens/

[PDF 다운로드](HowLens-3min.pdf) · 6페이지 · 16:9 · UR5e 데모는 9장면 전체 이미지로 수록.

`index.html`을 브라우저로 직접 열 수 있습니다. 사진·생성 이미지·스크립트·스타일을 모두 포함하므로 서버나 AI 호출 없이 발표할 수 있습니다. 폴더 전체를 함께 이동하세요. 발표자 창은 브라우저에서 팝업을 허용해야 합니다.

로컬 서버가 필요하면 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory docs/presentation
```

## 조작

- `←` / `→` / Space: 이전·다음 슬라이드. `Home` / `End`: 처음·마지막.
- `F`: 전체 화면. `S`: 별도 발표자 창. `N`: 현재 창 노트. `O`: 전체 슬라이드.
- `P`: 3분 타이머 시작·일시 정지. `R`: 타이머 초기화.
- 3번 슬라이드: 범위 탭, 1–9 장면 버튼, 자동 시연, 이미지 확대.
- 발표자 창과 관객 창은 슬라이드와 타이머를 공유합니다. 이미지 장면 조작은 관객 창에서 합니다.

## UR5e 자료와 편집 범위

사용자가 저장한 `howlens-ur5e-presentation-source.html`의 마지막 UR5e 답변을 사용했습니다. 해당 웹 대화의 응답 객체와 서버에 이미 생성된 이미지 9장을 확보했으며, 새 AI 요청은 하지 않았습니다. 원본 HTML은 발표 사이트에 포함하지 않습니다.

사용자 요청대로 화면의 질문은 **“어떻게 인스톨해?”** 한 문장입니다. 후속 발화들은 발표 화면에 포함하지 않습니다. 답변 도입은 발표용 요약이며, 9개 장면의 제목·설명과 이미지 바이트는 기존 결과를 유지했습니다. 슬라이드에는 저장된 결과 재생 및 대화 축약을 표시합니다.

이 결과의 범위는 현재 장착 상태, 매뉴얼의 부품 위치, 설치 담당자가 확인할 범위입니다. 설치·분해·배선·운전 절차나 설치 완료 판정을 제시한 결과가 아닙니다. 원래 응답의 `guide_plan`과 출처·이미지 해시는 `assets/provenance.json`에 있습니다.

참조 도면: [UR5e 공식 매뉴얼](https://s3-eu-west-1.amazonaws.com/ur-support-site/225353/710-965-00_UR5e_User_Manual_en_Global.pdf), 대화의 등록 문서 `ur5e-710-965-00-10.5.152`, PDF 12쪽 Figure 2.1. 업로드 사진은 사용자가 제공한 `UR5_cobot_with_teach_pendant.jpg`입니다.

## 검증 · 2026-10-09

Playwright Chromium에서 실제 파일을 열어 확인했습니다.

- 슬라이드 6장, 시간 배정 합계 180초, 키보드·버튼 이동, 전체 보기, 노트.
- 질문 편집, 이미지 9장 로드, 그룹·장면 선택, 확대 닫기, 자동 재생.
- 타이머 시작·일시 정지·초기화, 발표자 창 이동 동기화 및 공유 타이머.
- 데스크톱 1600×1000 / 1280×720, 모바일 390×844에서 페이지 가로 넘침 없음.
- 로컬 `file://`에서 기본 발표·이미지 로드 확인.
- JS 구문 검사 통과, 브라우저 JS 오류 0, 외부 네트워크 요청 0.
- 6장 스크린샷 직접 확인. 마지막 슬라이드의 사진은 의도적으로 캔버스 밖으로 이어지며 슬라이드에서 잘립니다.
- PDF 6페이지를 PNG로 렌더링해 한글·이미지·레이아웃 확인. 텍스트 추출로 질문 편집과 발표자 노트 제외 확인.

검증 스크립트·결과·스크린샷은 로컬 `HowLens-session-artifacts/20261009-presentation/`에 보존합니다. 웹 UI 검증은 실제 로봇 작업 검증과 구분합니다.

## 배포

`.github/workflows/presentation-pages.yml`은 `docs/presentation/`만 GitHub Pages에 업로드합니다. `main`에 이 폴더 또는 워크플로가 변경되면 다시 배포합니다.

템플릿 기반: html-ppt `presenter-mode-reveal`. 런타임·기본 CSS의 원저작자와 라이선스는 `THIRD_PARTY_NOTICES.md`를 참고하세요.

## PDF 다시 만들기

`export-pdf.cjs`는 Playwright Chromium으로 웹 슬라이드를 인쇄용 PDF로 만듭니다. Playwright를 사용할 수 있는 환경에서 `node docs/presentation/export-pdf.cjs`를 실행하세요. 기존 Chromium 경로는 `HOWLENS_CHROMIUM_PATH` 환경변수로 지정할 수 있습니다. 발표자 노트와 조작 도구는 PDF에 포함하지 않습니다.
