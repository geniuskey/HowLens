# HowLens agent entry point

Documentation lives in `docs/`. Use the role in your live Orca Task; do not infer it from the PC owner.

Read only these instructions at startup:
1. `docs/common/RULES.md`
2. Coordinator: `docs/orchestrator/START.md`; Worker: `docs/workers/<your-role>/START.md`
3. The shared contract and your Task card linked from that entry point.

Roles: `app` = 김의윤, `backend` = 이준영, `visual` = 이윤재, `evaluation` = 김태완.
Do not recursively read all of `docs/` or another role's instructions.
Read dependencies only through the public contracts or a specific coordinator-provided path.
Only Codex agents, each on its owner's PC and account. Product code belongs to Workers.
Do not edit shared contracts, other owners' code, or merge to main as a Worker.
User instructions and the live Orca lifecycle preamble take precedence over repository guidance.
